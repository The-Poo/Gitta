# Ordlista

| Term | Betyder |
|---|---|
| **repository** (repo) | Ett projekt med hela sin historik. Finns på GitHub och (efter clone) på din dator. |
| **GitHub** | Webbplatsen där dina repon lagras och delas. |
| **git** | Programmet på din dator som håller reda på historiken. |
| **commit** | Ett sparat steg i historiken, med en beskrivning. |
| **push** | Skickar dina commits från datorn till GitHub. |
| **pull** | Hämtar nya commits från GitHub till datorn. |
| **clone** | Hämtar ett projekt från GitHub till din dator första gången. |
| **branch** | En gren av projektet. Gitta jobbar på huvudgrenen (oftast `main`). |
| **remote / origin** | Adressen till projektet på GitHub. `origin` är standardnamnet. |
| **status** | Vad som ändrats sedan senaste commit. |
| **private** | Bara du och de du bjuder in kan se projektet. |
| **public** | Alla på internet kan se projektet. |
| **README** | Projektets förstasida (`README.md`). |
| **Markdown** | Enkelt textformat (`.md`) för README och dokumentation. |
| **token** | En nyckel som Gitta får av GitHub vid inloggningen, i stället för ditt lösenord. |
| **fast-forward** | När pull bara lägger nya commits ovanpå dina. Gitta gör bara sådana pulls. |

## Statusord i Gitta

| Ord | Betyder |
|---|---|
| ny | Filen är ny och inte sparad i historiken än |
| ändrad | Filen finns i historiken men har ändrats |
| borttagen | Filen har raderats |
| ● N ändringar | Projektet har osparat arbete |
| Allt sparat | Inget osparat |
